# Working agreement

## Ask before changing anything

Investigate freely, but change nothing without approval.

**Allowed without asking:** reading files and directories, searching, `git status` / `log` / `diff`, and any other read-only inspection.

**Requires approval first:** creating, editing, deleting or moving files; `git add`, `commit`, `push`; installing or changing packages, services, databases, or configuration; and any other command whose purpose is to modify state.

When approval is needed, show the exact change before making it — the proposed file contents, the exact diff, or the exact command — then stop and wait. Never make a change and ask for forgiveness afterwards.

**Exception:** when the current prompt explicitly authorises the change ("go ahead", "do it", "make the change", "apply it", "commit and push"), proceed without asking again. That authorisation covers only what was asked for in that prompt; it does not extend to later or different changes. A request to "review", "draft", "suggest" or "explain" is not authorisation. When in doubt, ask.
